# 🎵 Modern Music Player

A modern and responsive **Music Player** built using **HTML5, CSS3, and JavaScript**. It features a clean glassmorphism-inspired design with audio playback controls, playlist management, progress tracking, and keyboard shortcuts.

---

## ✨ Features

- ▶️ Play & Pause music
- ⏮️ Previous and ⏭️ Next song controls
- 🎵 Playlist with song selection
- 🖼️ Dynamic album cover display
- 📝 Song title and artist information
- ⏱️ Current time and total duration display
- 📊 Interactive progress bar with seek functionality
- 🔊 Volume control
- 🔀 Shuffle mode
- 🔁 Repeat mode
- ⌨️ Keyboard shortcuts
- 📱 Fully responsive design
- 🎨 Modern glassmorphism UI
- ⚡ Smooth animations and transitions
- 🎧 Autoplay next song

## ⌨️ Keyboard Shortcuts

| Key | Action |
|------|--------|
| Space | Play / Pause |
| ← Left Arrow | Previous Song |
| → Right Arrow | Next Song |

---

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/music-player.git
```

2. Open the project folder.

3. Add your music files (`.mp3`) to the `songs` folder.

4. Add album cover images to the `images` folder.

5. Open `index.html` in your web browser.
